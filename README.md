# ⚛️ ReactLearning

> **My journey of learning React by building real projects.**

Welcome to **ReactLearning** — a growing collection of hands-on projects I build while learning **React, JavaScript, modern frontend development, component-based architecture, state management, and responsive UI design**.

Instead of only following tutorials, I'm using this repository to **learn by building, experiment with concepts, make mistakes, refactor code, and gradually build more complete applications.**

---

## 🚀 About This Repository

This repository represents my **React learning journey**, starting with fundamental JavaScript and React concepts and gradually moving toward more interactive applications.

Each numbered project focuses on a specific concept or practical problem.

The goal is not just to complete projects, but to understand:

* 🧩 How React components work
* ⚛️ How state and props are used
* 🔄 How user interactions update the UI
* 🧠 How JavaScript concepts apply to React
* 📦 How to structure reusable components
* 🎨 How to create clean and responsive interfaces
* 🛠️ How to turn concepts into working applications

> **Learning principle:** Build → Break → Debug → Understand → Improve → Repeat.

## 💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/AkshaySatam79/ReactLearning.git
```

Move into the repository:

```bash
cd ReactLearning
```

Choose any project:

```bash
cd 12-eat-n-split
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

> **Note:** The exact commands may vary slightly depending on the individual project's setup.
